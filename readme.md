A comprehensive accessory pack for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** providing latex and bunny-themed cosmetic accessories designed to complement the Reverse Bunny Suit.

---

## 🎮 Features

Includes a wide selection of individually equippable latex accessories:
- **Head & Neck:** Bunny Ears, Detached Collar, Bowtie, Necktie, Necktie 2.
- **Arms & Hands:** Left Wrist Cuff, Right Wrist Cuff.
- **Body & Lower:** Bunny Tail, Heart Maebari, Heart Pasties, Latex Tube Top, Mini Skirt.
- Compatible with all standard game color palettes and interaction scenes.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.96.7`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/latex-accesories/releases) page and download `Reverse_Bunny_Accessories_v1.1.0.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Reverse_Bunny_Accessories_v1.1.0.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Reverse bunny accessories/mod.json
   ```
4. Launch the game and visit the Clothier / Wardrobe to equip the accessories.

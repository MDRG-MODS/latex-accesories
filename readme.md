A comprehensive accessory pack for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** providing latex and bunny-themed cosmetic accessories designed to complement the Reverse Bunny Suit.

---

## 🎮 Features

- **Head & Neck:** Bunny Ears, Detached Collar, Bowtie, Necktie, Necktie 2.
- **Arms & Hands:** Left Wrist Cuff, Right Wrist Cuff.
- **Body & Lower:** Bunny Tail, Heart Maebari, Heart Pasties, Latex Tube Top, Mini Skirt.
- Compatible with MDRG version **v0.97.12** (Target: `0.96.7`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/latex-accesories/releases) tab.
